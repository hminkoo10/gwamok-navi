# 2028 대학별 전형

대학별 「2028학년도 대학입학전형시행계획」(2026-04-30 공표)을 옮긴 자료다. 대학 하나에 파일 하나(`<대학 id>.json`). 고친 뒤 `node scripts/build-admissions.mjs`로 검사하고 `src/data/admissions2028.json`을 다시 만든다 (`--check`는 검사만).

- 원문에 있는 것만 적는다. 모르면 `null`이나 빈 배열.
- 숫자는 원문 표 그대로. 한 파일에 여러 캠퍼스가 있으면 그 캠퍼스 몫만 적는다.
- 이름이 같아도 수시·정시 전형은 따로 적는다.

## `<대학 id>.json`

```jsonc
{
  "univ": "korea",
  "planTitle": "2028학년도 고려대학교(서울) 입학전형시행계획",
  "date": "2026-04-30",
  "totals": { "수시": 2721, "정시": 1867 }, // 모집시기별 인원 (정원내+정원외). 모르면 null
  "changes": ["학교추천전형 교과 90%+서류 10% → 교과 80%+서류 20%"], // 2027 대비 변경, 60자 8개 안쪽
  "tracks": [
    {
      "id": "school-rec",
      "name": "학교추천전형",
      "type": "교과", // 교과 | 종합 | 논술 | 실기 | 수능 | 기타
      "period": "수시", // 수시 | 정시 | 기타
      "quota": "정원내", // 정원내 | 정원외
      "seats": 672, // 모르면 null
      "grads": "예정자", // 예정자 | 졸업자포함 | 졸업자 | null
      "rec": { "required": true, "limit": "고교별 12명" }, // 학교장 추천. 없으면 null
      "schools": { "only": [], "exclude": ["영재학교", "예술고"] },
      "regions": [], // 고교 소재 시도 조건
      "special": [], // 특별 자격
      "who": "국내 고교 졸업예정자, 고교별 12명 추천", // 100자 안쪽
      "method": "교과 80% + 서류 20%", // 100자 안쪽
      "elements": ["교과", "서류"], // 교과 | 서류 | 면접 | 논술 | 실기 | 수능
      "min": "의학과 국수영탐 4합 5", // 수능 최저. 없으면 null
      "subjects": "진로선택과목 성취도 반영", // 과목 이수 관련 언급. 없으면 null
      "note": null, // 80자 안쪽
      "pages": "11-12" // 원문 PDF 쪽
    }
  ]
}
```

- `schools`: 일반고 자율고 특성화고 마이스터고 직업계열 과학고 외고 국제고 예술고 체육고 영재학교 방송통신고 평생교육시설 검정고시 대안학교 해외고
- `regions`: 서울 부산 대구 인천 광주 대전 울산 세종 경기 강원 충북 충남 전북 전남 경북 경남 제주
- `special`: rural(농어촌) equity(경제적 배려) vocational(특성화고 등) worker(재직자) disabled(장애인 등) veteran(보훈) nk(북한이탈주민) overseas(재외국민·외국인) multicultural(다문화) island(서해5도) athlete(체육 특기) artist(예술 특기) military(군 위탁·계약학과) adult(성인학습자) other(그 밖, 자격은 `who`에). 여러 자격 중 하나면 되는 전형은 모두 적는다.
- `"ai": "YYYY-MM-DD"`: AI가 옮기고 사람이 원문과 견주지 않은 자료. 화면에 "AI가 옮김"이 붙는다. 확인했으면 지운다 (운영 중에는 관리 → 대입 자료의 확인함).

## `detail/<대학 id>.json`

반영 방법. `--check`가 모양과 합계를 검사한다.

```jsonc
{
  "univ": "korea",
  "suneung": [ // 정시 수능. 모집단위 묶음마다 하나
    {
      "group": "자연",
      "units": "자연계열 모집단위 (의과대학 제외)",
      "tracks": ["general-jeongsi"], // 빈 배열 = 정시 수능 전형 모두
      "use": "표준점수",
      "weights": { "국어": 20, "수학": 35, "영어": 15, "탐구": 30 }, // 합 100. 가감점만 하는 영역은 빼기
      "inquiry": "사회·과학 통합 2과목 평균",
      "english": "1등급 100, 2등급 97, …",
      "history": "4등급부터 등급당 0.2점 감점",
      "bonus": null,
      "formula": "…", // 원문 산출식, 400자 안쪽
      "total": 1000,
      "pages": "32-33"
    }
  ],
  "record": [ // 학생부 교과 성적
    {
      "tracks": ["school-rec"],
      "subjects": "국어·수학·영어·사회·과학 교과 전 과목",
      "terms": "1-1 ~ 3-1, 학년별 가중치 없음",
      "grades": "1등급 100, 2등급 98, …",
      "achievement": "A 100, B 95, C 90",
      "formula": "Σ(환산 점수 × 학점) ÷ Σ학점",
      "extra": "미인정 결석 3일당 1점 감점",
      "pages": "29-31"
    }
  ],
  "tracks": { // 전형별 상세
    "academic-excellence": {
      "stages": [
        { "step": "1단계", "pick": "5배수", "parts": { "서류": 100 } },
        { "step": "2단계", "pick": null, "parts": { "1단계": 80, "면접": 20 } }
      ],
      "interview": "제출 서류 기반 개별 면접 10분 내외",
      "essay": null,
      "docs": "학교생활기록부"
    }
  }
}
```

`parts`는 실질 반영 비율(%)이고 합이 100이다. 원문이 점수로만 적었으면 비율로 바꾼다.

## 다른 파일

- `units/<대학 id>.json`: 학과별 모집인원 `seats["<대학 id>:<학과>"]["<전형 id>"]`. 숫자는 인원, `null`은 뽑지만 학과별 인원이 없음, 없으면 뽑지 않음.
- `sources.json`: 원문 `url`, `file`, `sha`(sha256 앞 16자리). 게시글에서 열어야 받아지면 `page`(사람이 볼 글)와 `watch`(감시할 주소)도 적는다. 새 판으로 옮기면 `url`과 `sha`를 함께 바꾼다.
- 여기 없는 대학은 운영 서버가 시행계획을 받아 AI로 옮긴다 (`server/plan-import.ts`, 원문 주소 `server/plan-sources.json`). 그 자료는 서버 저장소에만 있다.
